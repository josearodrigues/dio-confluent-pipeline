## Limitações e interpretação

- A Costs API pode levar até 72 horas para disponibilizar os dados; os valores não representam necessariamente os encargos correntes do Console.
- A consulta padrão termina três dias antes da data UTC atual para reduzir a exposição ao atraso. Datas explícitas podem ser informadas como argumentos.
- A API agrega os itens diariamente. O campo `amount` é o valor após os descontos discriminados pela API.
- Quando `discount_amount` vier nulo/ausente em qualquer item, o resumo não apresenta uma soma global de descontos como se estivesse completa.
- O resultado não informa o saldo restante de créditos promocionais nem substitui a tela de Invoice Breakdown.
- A consulta exige papel OrganizationAdmin ou BillingAdmin. A autenticação é a sessão já configurada na Confluent CLI; o script não cria nem altera credenciais.
- Nenhum recurso, permissão, método de pagamento ou configuração Cloud foi alterado.
