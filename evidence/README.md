# Evidências

Este diretório recebe somente saídas geradas por execuções reais do laboratório.

- `local/`: comandos e verificações no PostgreSQL.
- `cloud/`: estado de recursos Confluent.
- `homologation/`: validações funcionais CDC e Flink.

Não criar arquivos fictícios para preencher esta pasta. Revise cada saída para remover segredos antes de versionar.
